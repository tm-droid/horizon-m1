# GPU audit: M1 TBDR under MakeUp (2026-11-10)

Source: m1-performance-r12/20261110-195836/source (fdc87ae + daily stack). Code-read only; gains are estimates.
Frame is GPU-bound (~34 ms under MakeUp at 2x Retina fullscreen).

## Ranked findings
1. **resolutionScale 100 at 2x Retina** (2560x1600 internal). 75 is estimated to save 8-12 ms. It softens the image, so it is a visual tradeoff: bench it and offer it to the user, do not change it silently. `Upscaling` enum (graphics.rs:435) offers Native/Quality/Balanced/Performance/UltraPerformance.
2. **One render pass per gbuffers stage**: pack_post.rs:3880-3917, begin() at :3966 :4038 :4143 :4257 :4433 :4485 :4522 :4606 :4658. Every boundary is a full tile store/load on TBDR. Merging same-target stages into one pass (write_mask per pipeline) is estimated at 3-6 ms.
3. **Vanilla world pass + blit still run under a pack**: gfx.rs:9879-9898 (keep_depth gfx.rs:9382), blit pack_post.rs:5473-5513. Skip them or use clear load ops: 1.5-2 ms.
4. **Alpha-test discard appended to all gbuffers fragments**: horizon-shaders/src/translate/mod.rs:592-605. This kills hidden-surface removal on opaque terrain (worse with the terrain-single-draw patch). A no-discard variant for OPAQUE_LAYER is estimated at 1-3 ms. Unconfirmed.
5. **Surface not framebufferOnly** (COPY_SRC/DST usage): gfx.rs:2607-2614, wgpu-hal metal/surface.rs:263. 0.3-1 ms.

## Smaller
- Start-of-frame B->A copies: pack_post.rs:5336-5344, 0.5-1 ms.
- Full mip chains: pack_post.rs:4849, 4879, 4705, 0.2-0.5 ms.
- shadowCache is off, and its key includes ticks/day_time: pack_post.rs:5177-5185.
- HUD: one pass per clip run (hud.rs:2872-2885); draw_range called twice (gfx.rs:11599/11627); pack_text alternates pipeline and bind group (hud.rs:2913-2923); full-screen vignette blend.

No blocking readbacks, a dedicated submit thread, 3 drawables, a 24-byte terrain vertex, aniso 1, no MSAA.
