## Overall
- No exfiltration, spawning, sockets, or writes outside game/config/save dirs seen. Native code is unsandboxed, so only trust the pinned SHAs above (`--trust-native-code`).
- Compile-compat with f42ef42 is the main risk, not security. Best hook match: minimap and Jade (hooks 359). CayMac mods and chatheads pin older horizon revs (ba6344a / 4aa6854); held_item_info is hooks 139; eatinganimation needs the missing .hmod.
- HUD overlap: CayMac HUDs and minimap use the shared `Corners` allocator, so they stack rather than overdraw; set distinct corners. Key clashes: toggle sneak `C` vs user's zoom `C`; light overlay F7 free; toggle sprint V.
- Install order (risk/benefit, one at a time): minimap, status_effect_hud, armor_status, light_overlay, toggle_sprint, chatheads, held_item_info, then Jade (scratch world first: writes game_rules.dat and patches 8 engine files), eatinganimation last/skip.
