## Findings for the coordinator
1. **sprite-compress-f42 does not apply to the build's source.** Against `launcher-data/native/stage` (and candidate-source,
   identical game.rs SHA `6e85c1de...`) all 3 `game.rs` anchors match 0 times (its reviewed pristine hash is `98291835...`).
   assets.rs and the example apply. The r2 script therefore leaves it out unless `R2_WITH_SPRITE=1`; fix its game.rs anchors
   against `stage` first. (My patches' anchors are disjoint from its edits; it must run before the u6 patches because it
   requires pristine assets.rs.)
2. **Audit #2 is not covered by qos-backport.** It only moves the three Far terrain/LOD threads (`far_terrain_current`).
   `behind()` stays a no-op on Apple, so the job pool (`jobs.rs`) and the LAN `horizon-chunk-encode-*` pool
   (`lan/chunks.rs:391`, never calls `behind_server`) are untouched. Gap remains; not implemented here.
