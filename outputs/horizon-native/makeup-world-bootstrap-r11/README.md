# Trace the MakeUp world bootstrap on R11

The timed `world` pass in `gfx/pack_post.rs::run` is the initial fullscreen draw that flips rows into the pack's GL coordinates, copies native color to the current colortex0 bank, converts reverse-Z depth with `1 - d`, and clears the other attached MRTs. Its median was 5.45 ms in the R11 sample and 5.41 ms in the stock AO comparison. The pass label includes the depth transfer and the clears, so those numbers cannot isolate the color copy.

The pinned MakeUp archive's only color0 sampler reference is `composite1_fragment.glsl`. It generates bloom from the mip chain of color0. With bloom enabled, the preceding `composite_fragment.glsl` uses `DRAWBUFFERS:016` and assigns its output 0 from the bloom source at the end of main. Its vertex stage uses the normal fullscreen transform. Active R11 logs show that both programs and final loaded, but do not expose translated attachment locations, actual read banks, or preflips. Those omissions matter because Horizon's main bank mask persists across frames, child compute may read before a draw, and an absent final presents color0 directly. The archive text suggests the optimization and the translated pipeline graph should establish whether it is safe.

`bootstrap-trace.patch` adds a one-time, opt-in pipeline trace at creation. Launch the resulting diagnostic build with `HORIZON_SHADER_PACK_BOOTSTRAP_TRACE=1` in a disposable exact-stack profile. Collect `bootstrap trace:` lines. Their post-pass slots are in execution order, followed by a geometry inventory. The group identifies where the geometry executes and whether buffer zero means the separate shadow bank. Child entries execute before their corresponding post pass. The format, depth blit, clears, preflips, per-pass read and write masks, mip requests, and viewports all appear. Translation and device execution remain unverified.

If the trace confirms the dependency, trial a depth-only shader helper for this exact pack/config while retaining the existing clear list. Keep the color copy if any active geometry or earlier post/compute samples buffer zero, when an intervening preflip changes the read bank, when the first writer is incomplete or blended, or when final is unavailable. For the first trial also require the exact pack hash and a diagnostic environment switch. Confirm that each buffer zero reader and mip generation sees the fully written side of `composite` across successive frames, including reloads. A successful trial should preserve appearance and improve whole-frame GPU time as well as the world pass. Use a fallback test with skipped composite and a pack that samples initial color.
