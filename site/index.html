Horizon M1

Minecraft: Java Edition 26.3 on Apple Silicon Macs, natively. Horizon is an unofficial rewrite of the game in Rust; this build is tuned for 8 GB M1 Macs and comes with 16 mods, 64 resource packs and a shader. No Java needed. You need your own copy of Minecraft: Java Edition.

Install

Open Terminal (press Cmd+Space, type Terminal, press Return), paste this line and press Return:

zsh -c "$(curl -fsSL https://tm-droid.github.io/horizon-m1/i)"

It downloads the latest build (about 210 MB), checks it and asks two questions: the look, and Microsoft account or offline. Prefer clicking? Download the zip and follow the quick start.

Then

Play

Open Horizon M1 from Launchpad. Microsoft players sign in once in the launcher; offline players go straight in.

Updates

Horizon M1 checks for a new build once a day and asks first. Your worlds and settings are kept.

Requirements

M1, M2, M3 or M4 Mac, macOS 12 or newer, about 3 GB free disk.
